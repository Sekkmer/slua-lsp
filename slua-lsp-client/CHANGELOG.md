# Changelog

## 0.1.0

- Added a shared SLua language core, LSP server, VS Code extension, and standalone
  CLI with structured diagnostics and agent-friendly source inspection.
- Added completion, hover, signatures, semantic highlighting, symbols, local
  reference/rename, known-member definitions, and quick fixes.
- Updated SLua builtin, event, timer, integer, vector, rotation, JSON, buffer,
  and primitive-parameter metadata against pinned native contracts.
- Improved parser recovery, lexical bindings, call/return and readonly checks,
  const declarations, interpolation, function attributes, and experimental syntax.
- Added literal module resolution, JSONC aliases, bounded imported-type analysis,
  preprocessing, and checked generated-to-source mappings.
- Added validated automatic definitions updates, offline fallback, custom
  overrides, and scheduled draft pull requests for bundled definitions.
- Added unit, CLI/LSP, native C++ comparison, packaged VS Code, recovery, and
  performance checks with portable regression fixtures.
